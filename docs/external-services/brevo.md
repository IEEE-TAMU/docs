# Brevo

We use [Brevo](https://www.brevo.com/) (formerly Sendinblue) as our transactional email provider.

It is used to send automated emails from our applications and services.

## DNS Configuration

SPF and DKIM records for Brevo are managed in the [infra repo](https://github.com/IEEE-TAMU/infra).

See [DNS Configuration](../infrastructure/cloudflare/dns.md) for an overview.
